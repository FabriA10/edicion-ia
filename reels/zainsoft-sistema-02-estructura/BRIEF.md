# Brief: serie «Qué es un sistema» de ZainSoft. Reel 2: cómo se construye un sistema (ciclo de vida)

## Pedido original
> "Continuamos con la segunda parte del video de ayer"
> (= Reel 2 de la serie, «Cómo se estructura»; ver `../zainsoft-sistema-01-que-es/BRIEF.md`)

## Objetivo
- Que el dueño de un negocio entienda que un sistema se compone de piezas conectadas, cada una con una función clara,
  y que no es «una página con extras».
- Público: dueños de negocios y emprendedores (ropa, canchas, gastronomía…), no técnicos.
- Acción final: seguir la cuenta @zainsoft_ y escribir por DM. Cierre genérico «Hay más para ver» (no anuncia el Reel 3).

## Contenido (CAMBIADO por el usuario el 2026-10-20: el reel pasa a ser el ciclo de vida del sistema)
- Pedido del usuario: «hablar muy por encima del ciclo de vida del desarrollo del sistema»: tomar las necesidades de los
  usuarios / requerimientos funcionales del cliente → estructurar el sistema según las necesidades del cliente y del propio
  sistema → desarrollar y documentar → implementar → mantener.
- Mensaje central: un sistema no se improvisa; se construye en etapas, partiendo de cómo trabaja tu negocio, y no termina
  con la entrega.
- Las 5 etapas (en la voz, palabras simples; en pantalla puede ir el nombre formal como rótulo):
  1. Escuchar / relevar las necesidades (requerimientos).
  2. Estructurar / diseñar el sistema según el negocio y lo que el sistema necesita.
  3. Desarrollar y documentar.
  4. Implementar (ponerlo en marcha en el negocio).
  5. Mantener (acompañar, ajustar, que siga funcionando).
- Analogía: la del edificio (decidida para este reel) aplicada a construir uno: escuchar qué necesitás → planos → obra y
  manual → inauguración → mantenimiento. Usarla solo si ayuda; no debe alargar ni tapar las etapas.
- Ejemplos: pueden aparecer rubros (ropa, canchas, restaurante) como guiños rápidos, sin que cada etapa necesite uno.
- Las 4 piezas (cliente / panel / datos / avisos WhatsApp) quedan confirmadas como funciones reales, pero ya no son el
  eje de este reel.
- Sin plazos, sin cifras, sin código en pantalla, sin jerga en la voz.
- Decidido (2026-10-20): @zainsoft_ va solo en pantalla, no se dice en la voz.
- Reel 3: se define después (usuario, 2026-10-20). Este reel no lo anuncia.
